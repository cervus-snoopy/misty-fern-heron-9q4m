# Everyday Wonder — The Coin That Sank Too Slowly

A single sentence about a small moment of wonder: a coin dropped into a fountain sinks so slowly through the green water that the wish tossed in with it gets time to reconsider halfway down. The surprise is not the coin, and not the person who threw it — it is the wish itself, changing its mind while it is still falling.

## Entry

`main.py` writes one sentence (under 200 characters) to `entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`). It reads nothing outside the repository and uses no network.
